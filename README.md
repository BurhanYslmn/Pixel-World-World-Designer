# Pixel Worlds — World Designer

**Pixel Worlds için ücretsiz dünya tasarlama aracı.**  
A free, browser-based world designer for Pixel Worlds.

🌐 **[Uygulamayı Aç / Open App](https://burhanyslmn.github.io/Pixel-World-World-Designer/)** · 💻 **[GitHub](https://github.com/BurhanYslmn/Pixel-World-World-Designer)**

**Languages:** Türkçe / English  
**Platforms:** Desktop / Mobile

---

## 🇹🇷 Türkçe — Kullanım Kılavuzu

### 🎮 Özellikler

| Özellik | Açıklama |
|---|---|
| 🌍 Dünya Boyutu | Varsayılan 80 × 57 blok (2560 × 1920 px). Manuel değiştirilebilir. |
| 🧱 Katalog | Blocks, Backgrounds, Props ve Worlds kategorileri. |
| 🎨 Tasarım | Blok yerleştirme, silme, kopyalama ve katman oluşturma. |
| 📋 Klonlama | Seçilen alanı kopyalama, taşıma ve onaylayarak yerleştirme. |
| ↩️ Geri Alma | Son yapılan işlemi geri alma. |
| 💾 Kayıt | PNG olarak indir veya JSON olarak kaydet ve düzenlemeye devam et. |
| 📱 Mobil | Dokunmatik çizim ve iki parmakla yakınlaştırma. |

### 🛠️ Araçlar

| Araç | Görevi |
|---|---|
| **Taşı** | Tasarım alanında hareket et. |
| **Silgi** | Yerleştirilmiş blokları sil. |
| **Damlalık** | Dünyadaki bir bloğu seç. |
| **Klonla** | Seçilen alanı başka bir yere kopyala. |
| **Geri Al** | Son işlemi geri al. |
| **Stack Blocks** | Aynı hücreye birden fazla katman yerleştir. |

### 📖 Nasıl Kullanılır?

1. **Dünya oluştur:** Varsayılan boyutları kullan veya istediğin ölçüleri gir.
2. **Görsel seç:** Sağdaki katalogdan Blocks, Backgrounds veya Props kategorisini aç.
3. **Tasarla:** Bir görsel seç ve dünyadaki istediğin hücreye yerleştir.
4. **Klonla:** Klonla aracını seç, alanı sürükleyerek işaretle ve hedefe dokun. Önizlemeyi sürükleyerek konumlandır. **✓** ile onayla, **×** ile iptal et.
5. **Kaydet:** PNG indir veya projeni JSON olarak kaydet. Daha sonra JSON dosyasını yükleyerek kaldığın yerden devam et.

**Telefon:** Tek dokunuşla blok yerleştir, iki parmakla yakınlaştır veya uzaklaştır. Taşı aracını kullanarak haritada gezinebilirsin.

## 🇬🇧 English — User Guide

### 🎮 Features

| Feature | Description |
|---|---|
| 🌍 World Size | Default 80 × 57 blocks (2560 × 1920 px). Customizable. |
| 🧱 Catalog | Blocks, Backgrounds, Props, and Worlds categories. |
| 🎨 Building | Place, erase, copy, and layer assets. |
| 📋 Cloning | Select, move, preview, and confirm copied areas. |
| ↩️ Undo | Reverse your last editing action. |
| 💾 Save & Load | Export PNG or save and reopen editable JSON projects. |
| 📱 Mobile | Touch controls and pinch-to-zoom support. |

### 🛠️ Tools

| Tool | Function |
|---|---|
| **Move** | Navigate around your world. |
| **Eraser** | Remove placed blocks. |
| **Picker** | Select an existing block from the canvas. |
| **Clone** | Copy a selected area to another location. |
| **Undo** | Reverse your last action. |
| **Stack Blocks** | Place multiple layers in the same cell. |

### 📖 How to Use

1. **Create a world:** Use the default dimensions or enter custom values.
2. **Choose assets:** Open Blocks, Backgrounds, or Props from the catalog.
3. **Build:** Select an asset and place it on the desired grid cell.
4. **Clone:** Select the Clone tool and drag to select an area. Tap a destination, drag the preview into position, then press **✓** to confirm or **×** to cancel.
5. **Save:** Export your design as PNG or save it as JSON. Import your JSON file later to continue editing.

**Mobile:** Tap to place blocks, pinch with two fingers to zoom, and use the Move tool to navigate around your world.
